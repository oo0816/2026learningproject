## 你要学会的东西

### Skill 是什么？

Skill = 流程知识包。它不是代码，而是告诉 agent "遇到什么情况时，按什么步骤做事"。

```
Skill ≠ Tool（工具是可调用的函数）
Skill ≠ MCP（MCP 连接外部数据源）
Skill = 给 agent 的"工作手册"——触发条件 + 步骤 + 模板 + 验收标准
```

### Skill 的结构

一个完整的 Skill 通常包含：

| 部分 | 作用 | 示例 |
|------|------|------|
| 触发条件 | agent 什么时候加载这个 skill | "当用户要求审查代码时" |
| 步骤流程 | agent 按什么步骤做事 | 1.读变更 2.检查安全 3.写报告 |
| 可用脚本 | skill 配套的工具脚本 | `run_tests.sh` |
| 输出模板 | agent 输出应该长什么样 | Markdown 报告模板 |
| Smoke test | 怎么验证 skill 能正常工作 | 输入 X → 预期输出 Y |

### 写好 Skill 的几个原则

1. **触达条件要具体**：不是"when user needs help"，而是"当用户提到 code review / CR / 审查代码 时"
2. **步骤要可执行**：每一步 agent 都能独立完成，不需要额外澄清
3. **给出反例**：除了告诉 agent 该做什么，也告诉它不该做什么
4. **控制长度**：SKILL.md 不是论文，300-500 行即可
