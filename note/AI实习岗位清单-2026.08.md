# 一、开发线（5 个）

## 1. MiniMax「Agent 产品研发」实习生

- **城市**：上海 ｜ **学历**：本科及以上，2026 届及以后毕业 ｜ **薪资**：面议（MiniMax 实习口碑较好）
- **岗位方向**：Agent 产品/能力定义、Agent Environment/Runtime/Infra 研发、多模态大模型训练环境/数据/Benchmark 构建
- **任职要求**：
  - 计算机/软件/人工智能相关专业
  - 熟悉 Python / Go / Java / C++ / Rust 任一语言
  - 有模型微调、Agent 设计开发经验者优先
- **匹配度**：⭐⭐⭐⭐ 城市对口、本科可投、语言门槛低；缺一个完整 Agent 项目（8 月底完成的命令行助手可当敲门砖）

## 2. 字节跳动「Agent 全栈开发实习生-数据平台」

- **城市**：北京 / 南京 ｜ **发布时间**：2026-08-19（最新）｜ **实习要求**：每周 4 天、连续 3 个月以上
- **岗位职责**：数据平台前端产品 + Agent 应用全栈研发（Web 前端、Node/BFF、服务端接口、Agent Skill）；建设 Prompt Engineering、Workflow、Multi-Agent、Tool Calling 技术方向
- **任职要求**：
  - Web 前端基础 + 掌握 Python / Java / Go / Node.js 至少一种服务端语言
  - 有大模型与 Agent 动手经验者优先
- **匹配度**：⭐⭐⭐ 最新鲜的岗位；但要求前端基础（React/Vue），你的差距在前端——投前确认愿意补
- **投递**：字节跳动官网招聘 / 牛客

## 3. 字节跳动「AI 开发实习生-抖音研发」

- **城市**：北京 ｜ **薪资**：约 500 元/天 ｜ **实习要求**：每周 4-5 天、连续 4 个月

  - 精通 Python / Go / Java / C++ 之一
  - 有 Prompt 调优、微调（SFT/LoRA）、RAG 或 Agent 框架开发经验
- **匹配度**：⭐⭐⭐ 方向与你计划的评测环节（RAGAS）重合；要求"精通"级编程——投前 Python 工程化（OOP/异步）必须补完

## 4. 蔚来「智能体实习开发工程师」

- **城市**：北京 ｜ **学历**：2026 年及以后毕业 ｜ **投递渠道**：飞书招聘页

- **匹配度**：⭐⭐⭐ 明确要求 Agent 框架——你计划里 LangGraph 12 月才深入，**建议 2026.12 项目二完成后投**
