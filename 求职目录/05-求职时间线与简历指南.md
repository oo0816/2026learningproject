## 二、简历诚实化重写方案（最重要的一步）

> 你的简历"有夸张成分"——不重写，面试就是大型翻车现场。原则：**只写能讲透 30 分钟的内容**。

### 逐段处理

**1. 教育背景**
- GPA 更新为 **86/100**（真实，且比简历上写的 83.7 更好——这是送分项）
- 课程保留高分核心课即可

**2. 大创项目（膝关节导航系统）—— 重点改造**
- 逐模块问自己：我真正动手做的有哪些？（跑实验？写数据增强？配准？还是主要做文档/组织？）
- **保留**：你能讲清楚原理和细节的模块（哪怕只保留 1-2 个）
- **降级**：参与过但讲不透的 → "参与 X 模块开发"
- **删除**：完全没沾手的
- 数字（Dice 94.32% 等）→ 只在你能解释"数据集、实验设置、对比方法"时保留；否则删数字，写方法不写指标
- 论文/软著 → 如实写作者顺序："参与发表论文 X 篇（第 X 作者）"
- 改写示例：
  - ❌ "设计基于 UNet++ 的 CT 骨骼分割算法，Dice 达 94.32%"
  - ✅ "参与 CT 骨骼分割实验（UNet++），负责数据预处理与训练调参，协助消融实验对比"

**3. 技能栏**
- "Python（熟练）" → "Python（可独立完成项目开发）"（等你做完 3 个项目后这句话就名副其实了）
- "C++（基础）" 保留；"SQL" 保留（课程设计是真的）
- 新增：**等你学完后**：LLM API 开发、RAG、LangGraph、FastAPI、Docker——每学会一个加一个

**4. 校园经历**：团支书、社会实践——保留（真实且是 PM 岗的加分素材）

**5. 求职意向**：改为 **"AI Agent 应用开发 / AI 产品经理（实习）"**，和你的双线目标一致

### 双版本简历

| 版本 | 侧重 | 写法 |
|---|---|---|
| 开发岗版 | 技术深度 | 项目放前面，技术栈、架构、评测数据 |
| PM 岗版 | 产品思维 | 校园经历+实践放前面，项目写"需求→设计→指标"逻辑，附作品集链接 |

> 简历上放 GitHub 链接 + 作品集（PRD/竞品分析 PDF）链接——**能点开的简历，面试率翻倍**。

## 三、面试准备计划

### 开发岗面试（八股范围，来自 hello-agents Extra01 + JD 高频）
- Agent 原理：ReAct 流程、规划/记忆/工具三大件、多智能体协作模式
- RAG：流程、chunk 策略、检索优化、Rerank、评估
- Function Calling：完整流程、常见坑（参数格式、幻觉调用）
- MCP：是什么、和 Function Calling 的关系
- 框架：LangGraph 的 StateGraph 机制
- 工程：FastAPI、Docker、异步、评测指标
- 手撕：用 Python 写一个简单的 agent 循环（面试高频）

### PM 岗面试（案例面 + 行为面）
- 案例题："设计一个面向 X 用户的 Agent 产品"（套路：用户→场景→任务拆解→技术可行性→评测指标→商业化）
- 行为题（STAR 法则，用真实经历）：团支书组织活动 / 企业走访 / 大创团队协作
- 作品集演示：5 分钟讲一个项目（背景→问题→方案→结果→反思）

### 防翻车专项（针对水分）
- 大创项目准备 30 分钟深挖稿：数据从哪来？指标怎么算？你负责哪部分？
- **模拟面试**：找 2 个同学/学长互相拷问，每周 1 次（认真做，比刷 100 题有用）
- 建立《面试问题库》：每次面试后记录被问的问题和你的回答，持续迭代

### 自我介绍模板（1 分钟版）
> "我是大连理工软件工程大三学生，GPA 86。做过医学图像的大创项目（说明真实角色），目前主攻 AI Agent 应用开发：独立完成了一个 RAG 知识库问答系统和一个基于 LangGraph 的多智能体学习助手（带链接）。同时对 AI 产品有持续研究，写过 X 篇产品拆解和 X 份 PRD。希望做 [Agent 开发 / AI 产品] 的实习。"
