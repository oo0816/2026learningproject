## 二、目标岗位的真实要求（来自实习 JD 的共识）

### 岗位 A：AI Agent 开发工程师（实习）

典型 JD 要求：
- Python 扎实（工程能力，不只是语法）
- 熟悉 LLM API 调用、Function Calling / Tool Use
- 理解 Agent 核心概念：规划、记忆、工具调用、多智能体协作
- 至少熟练一个框架（LangGraph / AutoGen / Dify）
- 了解 RAG、向量数据库、Prompt 工程
- 加分：MCP 协议、FastAPI/Docker 部署、评测与可观测性、有可展示项目（GitHub）

### 岗位 B：AI 产品经理（Agent 方向，实习）

典型 JD 要求：
- 产品基本功：需求分析、竞品分析、PRD、原型、数据分析
- AI 技术认知：LLM 能力边界、Prompt、RAG、Agent 架构（任务拆解/记忆/工具）、评测指标
- Agent 产品设计：把业务拆成"用户目标 → 任务链路 → 工具调用 → 人机协同节点 → 评估指标"
- 关注行业动态（OpenAI/Anthropic/字节/阿里 的 Agent 产品）
- 加分：能用 Coze/Dify 搭 demo、懂技术（→ 这是你的差异化！）

### 关键洞察（你的双线策略的依据）

1. **两条线 JD 有大量重叠**：LLM 认知、Agent 原理、RAG、评测——这就是"共用底座"
2. **"懂技术的 PM" 和 "懂产品的工程师" 都极度稀缺**：双线并行不是浪费，是差异化
3. **开发线是更难补的那条**（需要大量代码实践），所以前期时间倾斜给开发
4. **产品线可以靠"文档产出"快速积累作品集**（PRD/竞品分析不需要实习就能做），后期补来得及

## 三、双线并行的具体玩法

### 共用底座（每学一个知识点，双视角看）

| 知识点 | 开发视角 | 产品视角 |
|---|---|---|
| ReAct 范式 | 手写实现，理解循环逻辑 | 思考"什么时候该让模型想/该调用工具" |
| RAG | 调通检索链路，优化 chunk/rerank | 思考"用户什么场景需要引用来源" |
| 评测指标 | 写评估脚本、跑 RAGAS | 设计"任务成功率/人工接管率/成本"指标体系 |
| MCP 协议 | 接入工具服务器 | 思考"Agent 能力边界怎么扩展、怎么定价" |
| 行业产品 | 看技术实现（如何做 memory） | 拆解产品定位/交互/商业模式 |

### 项目双产出（详见 `03`）

```
项目一：个人知识库问答助手（RAG）
  → 开发产出：GitHub repo + 部署链接 + demo 录屏
  → 产品产出：竞品分析报告 + PRD + 评测方案
```

### 学习节奏（周模板详见 `02`）

- **学期中**：工作日每晚 1.5-2h + 周末 6-8h ≈ 15-18h/周
- **寒暑假**：每天 6-8h ≈ 40h+/周（暑假是最黄金的时间，别人玩你弯道超车）

## 四、决策自测清单（决策点 1 用：2027.01 寒假）

做完两个项目后，诚实地回答以下问题（每题 1-5 分）：

**开发线倾向**
1. 我 debug 到深夜解决问题后，有成就感吗？
2. 我愿意花 2 小时读官方文档/英文教程弄懂一个 API 吗？
3. 看到别人写的优雅代码，我想模仿并超越吗？
4. 让我连续一周写代码不跟人交流，我会开心吗？

**产品线倾向**
5. 我享受分析"用户为什么需要这个功能"吗？
6. 我愿意为了讲清楚一个需求，画原型/写文档反复改吗？
7. 我享受跟不同角色（研发/设计/业务）沟通推动事情吗？
8. 看到市场报告/竞品动态，我会兴奋地思考"我们该怎么做"吗？

**判定**：
- 开发 ≥ 18 分 → 主线选开发，产品线作为加分项
- 产品 ≥ 18 分 → 主线选产品（你的技术背景就是最大差异化）
- 都高 → 继续双线，投"技术型 PM"或"Agent 开发+产品感"的岗位
- 都低 → 不是岗位问题，是学习节奏问题，先按计划走，项目做出感觉再说

## 五、防翻车清单（针对简历水分）

1. **大创项目逐模块梳理**：你真正动手的是哪几个模块？（分割？配准？还是只写了文档/跑实验？）把"能讲透 30 分钟"的模块留下，其余降级为"参与"或删除
2. **数字要能解释**：Dice 94% 怎么算的？测试集多大？对比方法在哪跑的？——答不上来的数字就是炸弹
3. **论文/软著如实表述**：你排第几作者？贡献是什么？"参与发表 5 篇论文"比"产出 5 篇论文"安全且体面
4. **GPA 更新**：写真实的 86 分（均分），比旧的 83.7 更有优势
5. **"熟练"改"基础/了解"**：Python、C++ 等技能按真实水平写，面试官现场出题时你不会慌
6. **原则**：简历可以包装，但不能虚构。**包装 = 用最好的方式讲真话；虚构 = 面试翻车现场**
