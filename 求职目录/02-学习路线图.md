## 📅 阶段 1：共核筑基（2026.07-08 暑假，约 8 周）⭐ 黄金时间

**目标**：徒手实现一个带工具调用的 ReAct Agent + 建立产品视角

### 开发线任务（70% 时间）

**第 1-2 周：Python 工程化补强**（你简历写"熟练"但实际是基础，这 2 周把它补真）
- OOP 深入：类设计、继承/组合、`__init__`/`__call__`/`__enter__`
- 类型注解、`dataclass`、装饰器（写几个实用装饰器）
- 异步入门：`asyncio`、`async/await`、`aiohttp`（LLM 调用全是异步，早晚要会）
- 依赖管理：venv + requirements.txt / uv；pytest 写 5 个测试
- 建议资源：廖雪峰 Python 教程（挑 OOP/异步部分）+ 官方文档

**第 3-5 周：完成 hello-agents 第 4-6 章（动手为主）**
- 第四章 智能体经典范式：**手写** ReAct、Plan-and-Solve、Reflection（不抄代码，看完自己写一遍）
- 第五章 低代码平台：用 Coze/Dify 各搭一个 Agent，体验"产品视角"的 Agent 搭建（为产品线埋伏笔）
- 第六章 框架实践：LangGraph 入门（先看概念，第 6 周再深入）
- 同步补 LLM API 实战：chat 补全、Function Calling（关键！）、Streaming、结构化输出
- 每天读 DeepLearning.AI 免费短课 1 节（Function Calling / Prompt 相关，有中文）

**第 6-8 周：第一个完整小项目（见 `03` 项目一的前身版）**
- 用 LangGraph 或纯手写，做一个"命令行版 AI 助手"：能调用 2-3 个工具（查天气 API、计算器、文件读写）
- 完成 hello-agents 第 7 章（构建自己的 Agent 框架）——理解框架内部原理
- 产出：项目推 GitHub，写 README（中文，讲清楚架构）

### 产品线任务（30% 时间）

- [ ] 产品基础入门：读完《人人都是产品经理》前 6 章 or 免费课程（需求分析、PRD 结构、竞品分析方法）
- [ ] 每周拆解 1 个 AI 产品，写 1 篇笔记（候选：豆包、Kimi、秘塔 AI 搜索、扣子、Notion AI、ChatGPT）：产品定位 / 目标用户 / 核心功能 / 交互亮点 / 商业模式 / 技术猜测
- [ ] 用 Coze/Dify 搭建时，刻意用"产品经理"视角记录：用户是谁、任务链路怎么设计、失败了怎么办

**产出物**：① 手写 ReAct Agent 代码（不用框架）② 命令行 AI 助手项目（GitHub）③ 4-6 篇产品拆解笔记

**验证标准（暑假结束）**：
- 能不看教程，30 分钟内写出一个 ReAct 循环（prompt→LLM→工具→循环）
- 能讲清楚 Function Calling 的完整流程（模型输出 JSON → 代码解析 → 调用 → 回填）
- 产品笔记 ≥ 4 篇，每篇 ≥ 500 字

## 📅 阶段 2：RAG + 项目一（2026.09-11 大三上，约 12 周）

**目标**：完成第一个完整可部署的 RAG 产品（双产出）

### 开发线任务

**第 1-4 周：RAG 全流程（hello-agents 第 8 章 记忆与检索）**
- Embedding 概念、向量数据库（Chroma 起步 → Qdrant/Milvus）
- 文档加载 → Chunking 策略 → 向量化 → 检索（相似度/混合检索）→ Rerank → 生成
- RAG 评估：RAGAS 框架 or 自建 30 条评测集（理解"答得好不好"怎么量化）
- 补充：FastAPI 入门（写一个 `/chat` 接口），Docker 打包

**第 5-8 周：项目一 个人知识库问答助手（详见 `03`）**
- 选题：你自己的学习资料/课程笔记做知识库，做"能回答我自己的笔记"的助手
- 技术栈：FastAPI + Qdrant/Chroma + DeepSeek/通义 API + Docker
- 目标：能部署、能访问、能回答、能给出引用来源

**第 9-12 周：LangGraph 深入 + 上下文工程**
- hello-agents 第 9 章（上下文工程）、第 10 章（MCP/A2A 协议）——MCP 是 2026 年 JD 高频词，必学
- LangGraph：StateGraph、节点/边、多智能体协作（supervisor 模式）
- 读 LangGraph 官方教程 + DeepLearning.AI 免费课《AI Agents in LangGraph》

### 产品线任务

- [ ] 为项目一写完整 PRD（背景/用户/需求/功能/流程/边界/指标）——不会写就先找模板，抄结构
- [ ] 写竞品分析报告：知识库问答赛道（Notion AI / ChatPDF / 秘塔 / Kimi 长文）选 3 个对比
- [ ] 学习原型工具：Figma 或墨刀，为项目一画出 5-8 个页面的低保真原型
- [ ] 继续每周 1 篇 AI 产品拆解（重点转向 Agent 类产品：Manus、扣子空间、ChatGPT Tasks 等）

**产出物**：① 项目一完整代码（GitHub，含 README/部署文档/demo 录屏）② 项目一 PRD + 竞品分析 + 原型 ③ 4 篇产品拆解

**验证标准（11 月底）**：
- 项目一可演示：打开网页 → 提问 → 得到带引用的回答（录屏 3 分钟）
- 能讲清楚 RAG 每个环节的取舍（chunk 大小为什么这么设？为什么用 rerank？）
- 能用 10 分钟讲完 PRD 的核心逻辑

## 📅 每周执行模板（学期中）

```
工作日（周一至周五）每晚 1.5-2h：
  开发线（优先）：学新知识/写项目代码  ≈ 60-75 分钟
  产品线（碎片）：拆解文章/PRD/笔记    ≈ 20-30 分钟
  输入（碎片时间）：听播客/读公众号（Founder Park、硅谷101、晚点）

周末（周六日共 6-8h）：
  大块时间（4-5h）→ 只做项目（代码或文档），不学新知识
  复盘 30 分钟：本周做了什么/产出什么/下周计划（填下表）
  剩余 → 输出：写笔记、写 PRD、录 demo

每周复盘（周日晚 15 分钟）：
  本周完成的任务：
  本周产出物（代码/文档/笔记）：
  卡住的问题（→ 查文档 or 问社区 or 记录）：
  下周最重要的 3 件事：
```

**暑假/寒假版**：每天 6-8h，上午开发（大脑清醒写代码）、下午开发/项目、晚上产品线 + 复盘。
