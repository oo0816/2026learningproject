### 阶段 A：L5 收尾 + L6 选题定型（2026.10-11，约 7 周）

**目标**：把"学习练习"阶段正式收官，确定最终项目方向。

- [ ] 接一个**真实 MCP server**（不是自己手写的玩具版），把 L4 真正闭环
- [ ] 跑完 L5 的 **15 项 eval**，填 `evals.md`，写 `notes/l5-agent-eval-framework.md`（评测该测什么、bad case 怎么设计）
- [ ] 补 L2 的验收记录（测试结果 + C 线验证），把欠账清零
- [ ] **L6 选题定型**（详见 `03`）：从"能体现差异化"的方向里定 1 个
- [ ] 技术补强（为项目三铺路）：FastAPI 写一个 `/chat` 接口；Docker 把任一项目打包成一条命令能跑起来

**验证标准**：能 5 分钟讲清"Agent 评测怎么设计、指标怎么定"；能演示一个可部署的项目

### 阶段 B：L6 项目完成 + 成品化（2026.12-2027.01 寒假，约 7 周）⭐ 黄金期

## 三、产品线详细安排（重点）

> 产品线不是"另开一门课"，而是**给已经做出来的技术项目配一整套产品文档**。你的技术线已经很强了，产品线现在是唯一完全空白的部分——这一节就是把它补上。

### 3.1 产品线要交的"总账"（这就是 PM 岗简历 + 作品集的全部弹药）

| # | 产出物 | 数量目标 | 截止 | 现状 |
|---|---|---|---|---|
| 1 | 竞品分析报告 | 3-4 份（每个项目 1 份） | 2027.04 | ⬜ 0 |
| 2 | PRD（产品需求文档） | 3 份（每个项目 1 份） | 2027.04 | ⬜ 0 |
| 3 | 低保真原型 | 3 套（各 5-8 页） | 2027.04 | ⬜ 0 |
| 4 | 用户调研纪要 | 1 份（访谈 3-5 人） | 2027.01 | ⬜ 0 |
| 5 | 项目复盘文档 | 3 份 | 2027.04 | ⬜ 0 |
| 6 | AI 产品拆解笔记 | 20 篇（精选 5 篇进作品集） | 2027.04 | ⬜ 0（本周启动） |
| 7 | 行业报告《2027 年 Agent 产品形态盘点》 | 1 篇 | 2027.04 | ⬜ 0 |
| 8 | 作品集 PDF（打包上表） | 1 套 | 2027.04 | ⬜ 0 |

### 3.2 分阶段任务

#### 阶段 A（2026.10-11）—— 打地基

- [ ] **产品基础入门**：读《人人都是产品经理》前 6 章 或 aipmbook.cn，掌握三件事——需求分析、PRD 结构、竞品分析方法（每周 2-3 小时）
- [ ] **建立拆解笔记模板**（统一字段：产品定位 / 目标用户 / 核心功能 / 交互亮点 / 商业模式 / 技术猜测），启动"每周 1 篇"，到 11 月底累计 **6 篇**
- [ ] **第一份竞品分析**（练手）：对比 Notion AI / ChatPDF / 秘塔 AI 搜索——定位、功能、交互、收费、优劣
- [ ] **原型工具上手**：Figma 或墨刀，跟 B站"低保真原型"教程 2-3 小时，跑通第一张图

#### 阶段 B（2026.12-2027.01 寒假）—— 产品文档集中产出期

- [ ] **项目一（RAG）完整 PRD**：背景 / 目标用户 / 需求 / 功能清单 / 核心流程（上传→分块→检索→回答）/ 边界与异常 / 评测指标（回答准确率、引用正确率、首字延迟）
- [ ] **项目二（多智能体）PRD 进阶版**：用户目标 → 任务链路拆解 → 每个节点的工具/上下文/异常处理 → 人工介入点 → 评测指标（任务完成率、人工接管率、工具调用成功率、成本/次）
- [ ] **原型两套**（各 5-8 页低保真）
- [ ] **用户调研**：访谈 3-5 名目标用户（同学 / 医学生），记录**原话**，写成调研纪要——PM 面试最看重"你真的见过用户"
- [ ] 拆解笔记累计到 **12 篇**
- [ ] 决策点 1 打分 → 初定主线；简历 v1 双版本（PM 版把校园经历和实践放前面）

#### 阶段 C（2027.02-04）—— 差异化 + 打包成册

- [ ] **项目三完整产品文档**：竞品分析（PubMed GPT / 文献鸟 / ChatPDF）+ PRD + 复盘
- [ ] 补齐**三份项目复盘文档**（技术选型、踩坑、数据、改进方向）
- [ ] 拆解笔记累计到 **20 篇**，挑 5 篇精修
- [ ] 写**行业报告**《2027 年 Agent 产品形态盘点》（对比 Manus / ChatGPT Agent / 扣子空间 / 通义等）
- [ ] **作品集打包成 PDF**：竞品 ×3-4 + PRD ×3 + 原型 ×3 + 复盘 ×3 + 拆解精选 ×5 + 行业报告 ×1
- [ ] **PM 岗面试准备**：案例题套路（用户 → 场景 → 任务拆解 → 技术可行性 → 评测指标 → 商业化）；行为题 STAR；5 分钟项目演示稿

#### 阶段 D-F（2027.05 起）—— 面试与实习

- [ ] 面试中被问到的产品问题，全部进《面试问题库》
- [ ] 实习期间写 PM 视角周报，沉淀业务理解 → 秋招素材
- [ ] 秋招：刷产品案例分析题，每周末 1 次模拟面

### 3.3 产品线的"每周最小动作"（雷打不动）

```
每周固定（再忙也要做）：
  · 1 篇 AI 产品拆解笔记（30-60 分钟，用统一模板）→ 到 2027.04 攒够 20 篇
  · 1 次"产品视角回看"：把本周写的代码，用产品经理的眼睛重看一遍
    （用户是谁？失败了怎么办？这个功能值不值？）→ 写 3 句话进学习日记

冲刺期（阶段 B/C）额外：
  · 每 2 周产出 1 份正式文档（竞品 / PRD / 原型 / 复盘，轮着来）
```

### 3.4 产品线用什么学

见 `04-资源清单.md`（产品基础、AI 产品认知、拆解素材源、原型工具）。

**原则**：先学框架（需求 / PRD / 竞品），再在真实项目里用一遍——**不要把产品线当"课"来学，要当"作业"来做**。

## 📅 每周执行模板（学期中）

```
工作日（周一至周五）每晚 1.5-2h：
  开发线（优先）：学新知识 / 写项目代码   ≈ 60-75 分钟
  产品线（碎片）：拆解文章 / PRD / 笔记   ≈ 20-30 分钟
  输入（碎片时间）：听播客 / 读公众号（Founder Park、硅谷101、晚点）

周末（周六日共 6-8h）：
  大块时间（4-5h）→ 只做项目（代码或文档），不学新知识
  复盘 30 分钟：本周做了什么 / 产出什么 / 下周计划（填下表）
  剩余 → 输出：写笔记、写 PRD、录 demo

每周复盘（周日晚 15 分钟）：
  本周完成的任务：
  本周产出物（代码/文档/笔记）：
  卡住的问题（→ 查文档 or 问社区 or 记录）：
  下周最重要的 3 件事：
```

**暑假 / 寒假版**：每天 6-8h，上午开发（大脑清醒写代码）、下午开发/项目、晚上产品线 + 复盘。
